# AWS WAF Token Setup

UW-Madison's enrollment API now requires an AWS WAF token for all requests. This document explains how to automatically generate and update the token.

## Overview

The WAF token:
- Is automatically generated by visiting the enrollment site
- Expires after ~4 days
- Must be included in API requests as a cookie and header

## Setup

### 1. Generate Token Locally

To test token generation:

```bash
npm run waf:token
```

This will output the token to the console.

### 2. Update GitHub Secret Manually

1. Generate a token: `npm run waf:token`
2. Copy the token
3. Go to GitHub repository → Settings → Secrets and variables → Actions
4. Add or update secret named `AWS_WAF_TOKEN` with the token value

### 3. Automatic Updates (Recommended)

The GitHub Actions workflow automatically updates the token every 3 days.

#### Setup Personal Access Token (PAT)

To enable automatic secret updates, you need a GitHub Personal Access Token:

1. Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Generate a new token with `repo` scope
3. Add it as a repository secret named `PAT_TOKEN`

The workflow will use this PAT to update the `AWS_WAF_TOKEN` secret automatically.

#### Workflow Schedule

The workflow runs:
- **Every 3 days** at 2 AM UTC (token expires after ~4 days)
- **On manual trigger** via GitHub Actions UI
- **On push** to workflow files

## Usage in Code

The token should be used in API requests:

```javascript
const headers = {
    'Cookie': `aws-waf-token=${process.env.AWS_WAF_TOKEN}`,
    'x-aws-waf-token': process.env.AWS_WAF_TOKEN,
    // ... other headers
};
```

## Troubleshooting

### Token Generation Fails

- Check internet connection
- Verify Puppeteer dependencies are installed
- Try running with `headless: false` to see what's happening

### Secret Update Fails

- Verify `PAT_TOKEN` secret exists and has correct permissions
- Check GitHub Actions logs for specific error messages
- Fallback: Update secret manually using `npm run waf:token`

### API Requests Still Fail

- Verify token is being included in requests
- Check token hasn't expired (expires after ~4 days)
- Ensure all required headers are present
